# Tasks

行为依据：`openspec/specs/product-center/`（随 `init-wms-foundation` 归档生效）。

前置：`implement-owner` 已交付登录、权限、数据范围与货主模型。本变更不改行为，只做实现。

## 1. 品类与品牌

- [ ] 1.1 实现品类树与必填项模板，验证选择品类后模板要求追加到提交校验、品类最多两级、不支持第三级入口
- [ ] 1.2 实现品牌货主级隔离，验证两个货主可建同名品牌、建档时品牌列表只出现本货主品牌

## 2. 商品建档

- [ ] 2.1 实现 SKU 建档与 SKUID 生成（四位前缀 + 六位流水），验证前缀全局唯一、流水按货主独立、驳回重提沿用原 SKUID
- [ ] 2.2 实现主档单品尺寸与包装箱规的单一口径，验证主档只存单品尺寸、包装层级仅内箱与外箱可录箱规
- [ ] 2.3 实现分阶段必填校验，验证草稿仅校验三项、提交审核全量校验、含电池未填类型被拒
- [ ] 2.4 实现商品备注与图片（1-5 张），验证超出上限被拒

## 3. 条码与包装

- [ ] 3.1 实现条码管理与货主维度唯一约束，验证两个货主可建相同条码且第二个货主收到通用提示、不展示占用方信息、同货主同条码建档被拒
- [ ] 3.2 实现条码定位入口，验证有单据时按货主加条码唯一定位、未命中直接报错不弹候选、无单据时多命中列候选、零命中报错
- [ ] 3.3 实现无上下文扫码的候选列表，验证每行显示货主与商品名、按最近出库时间倒序（首期该字段预留）、选定后记录操作人时间与候选数量
- [ ] 3.4 实现链式包装层级，验证三层换算正确、非正整数被拒、不提供托盘层、单品层尺寸取自主档

## 4. 审核

- [ ] 4.1 实现审核状态机与自动通过规则，验证合规档案自动通过、异常项进入人工队列、批量通过逐条留痕
- [ ] 4.2 实现关键字段重审与待审版本，验证改箱规生成待审版本且业务仍读生效版、改名称直接生效、通过后覆盖生效版、同一 SKU 待审版本唯一
- [ ] 4.3 实现审核状态与启停状态独立，验证未通过审核不可启用、停用不改审核状态、恢复启用只做字段校验不重新审核
- [ ] 4.4 实现商品停用与恢复启用，验证恢复时重新执行提交校验、缺字段被拒并列出

## 5. 导入与标签

- [ ] 5.1 实现 SKU 批量导入（只新增），验证 2 万行上限、行级失败不阻断其他行、已存在编码被拒且原商品不被修改、同货主并发导入被拒
- [ ] 5.2 实现标签 PDF 生成与打印记录，验证 Code128 可扫、标签为 40×20mm 且只含 SKUID 与货主简称、草稿态带水印、单次超 500 张被拒、有条码商品不强制贴标

## 6. 两端页面

- [ ] 6.1 实现货主端商品列表与详情（游标分页、总数缓存），验证 30 万行数据下翻页无大偏移量查询
- [ ] 6.2 实现货主端商品建档表单（六段折叠、分阶段保存、品类模板联动），验证草稿保存与提交审核的校验差异、未填项计数准确
- [ ] 6.3 实现货主端批量导入页（模板下载、进度轮询、错误报告下载），验证中断后可重传
- [ ] 6.4 实现货主端标签打印页（预览、张数、水印），验证打印记录出现在仓网端
- [ ] 6.5 实现仓网端商品审核队列页（三栏、差异对比、批量通过），验证重审版本左右对比标出变更字段
