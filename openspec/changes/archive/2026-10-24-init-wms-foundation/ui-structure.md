# 界面承载

首期 15 个页面，两个端。作为 PRD「界面」一节的原料。

## 一、页面清单

| 端 | 页面 |
| --- | --- |
| 仓网管理端（11） | 登录、找回密码、用户管理、角色管理、系统设置、货主列表、货主新建、货主详情、商品列表、商品审核、品类管理 |
| 货主端（5） | 登录、商品列表、商品建档、商品导入、标签打印 |

仓库网络相关的 8 个页面（仓库列表、仓库新建、仓库详情、空间树、货架模板与生成、建仓向导、运输资源、库位导入）随范围后置。

---

## 二、登录（两端共用形态）

**仓网端**：账号密码 + 可选的动态验证码。页脚显示系统名称与版本号。

**货主端**：同一表单，账号为系统生成的货主编码。

**失败处理**：连续失败按策略锁定，锁定后提示剩余时间。

**登录表单下方**：忘记密码（跳找回密码页）。

**未完成配置的引导页**

登录成功后若账号无角色或货主范围为空，不进工作台，跳转引导页：

```
你的账号尚未完成配置
请联系管理员为你分配角色与数据范围
将在 20 秒后自动退出
```

倒计时结束自动终止会话。

---

## 三、找回密码

两个状态在同一条路由上。

**状态一 · 申请**

```
邮箱找回密码
请输入登录名，我们会向绑定的邮箱发送重置链接

[ 登录名            ]
[ 发送重置链接 ]

← 返回登录
```

提交后无论账号是否存在、是否有邮箱、是否已停用，**一律显示同一句**：

```
如果该账号存在且绑定了邮箱，重置链接已发送，请查收
```

**状态二 · 重设密码**

从邮件链接进入，URL 带令牌。

```
设置新密码
[ 新密码      ]
[ 确认新密码  ]
[ 提交 ]

链接 30 分钟内有效，仅可使用一次
```

令牌无效或过期时，页面不显示表单，只显示「链接已失效」与「重新申请」按钮。

**货主端同一套页面**，仅品牌色与文案不同。

## 四、用户管理

**列表列**：登录名、姓名、主体类型（内部员工/货主）、角色、货主范围摘要、状态、最后登录、操作

**操作**：编辑、重置密码、停用

**顶部**：新建用户

**新建/编辑表单**

| 段 | 字段 |
| --- | --- |
| 账号 | 登录名（货主用户自动生成，内部员工手填）、姓名、主体类型 |
| 归属 | 所属货主（主体类型为货主时必填） |
| 授权 | 角色（可多选）、货主范围（默认继承角色，可展开覆盖） |

**货主范围覆盖区**

默认折叠，展开后两选一：全部 / 指定货主（多选下拉）。

---

## 五、角色管理

**列表列**：角色名称、标识、权限点数、用户数、货主范围默认值、状态、操作

**操作**：编辑、分配用户、删除

**顶部**：新建角色

**编辑页**

| 区块 | 内容 |
| --- | --- |
| 基本信息 | 角色名称、标识、排序、备注 |
| 功能权限 | 权限点树，按模块分组，勾选到操作级 |
| 数据范围默认值 | 货主维度两选一：全部 / 指定货主 |

**约束**：超级管理员角色带内置标记，不可编辑不可删除；删除角色时若仍有用户占用，拒绝并提示人数。

## 六、系统设置

三个页签合一页，减少菜单层级。

### 页签一 · 数据字典

左侧字典类型列表，右侧字典项表格。

字典项列：名称、编码、排序、状态、操作。支持中英双语名称。

### 页签二 · 编码规则

表格列：规则名称、前缀、流水位数、当前值、示例、操作（编辑）

首期两条规则：货主编码（`OWNER` + 4 位）、SKUID（货主前缀 + 6 位）。

流水不可回拨，只允许查看与调整前缀。

### 页签三 · 审计日志

筛选：时间范围、操作人、对象类型、操作类型

表格列：时间、操作人、对象、操作类型、变更摘要

只读，无删除入口。

## 七、货主列表

**筛选栏**：名称、编码、类型、状态、主负责人

**表格列**

| 列 | 说明 |
| --- | --- |
| 系统编码 | 等宽字体 |
| 客户名称 | 点击进详情 |
| 客户类型 | 标签样式 |

| 更新时间 | — |
| 操作 | 查看、编辑、状态流转、终止 |

**顶部**：新建货主

**约束**：终止状态的货主仍出现在列表中，写操作按钮置灰。

## 八、货主新建

单页表单，只有一段：

| 字段 | 必填 |
| --- | --- |
| 客户名称 | 是 |
| 客户类型 | 是 |
| 结算主体 | 是 |
| 备注 | 否 |

**设计理由**：建档只收能让列表认出这一行的最少信息，其余字段在详情页按页签补。

**底部操作**：取消、创建。创建后跳详情页，停在「基本信息」。

## 九、货主详情

**头部**

```
宝安一号仓供应链有限公司                    [合作中]
OWNER0001 · 主负责人 张三 · 更新于 2026-10-23 14:30
                                          [编辑] [状态流转] [终止]
```

**页签**：基本信息 / 联系人 / 税号 / 账号

**右上角**：操作日志（抽屉，不占页签）

合作仓与合同两个页签随范围后置，本期不出现。

### 页签一 · 基本信息

| 分组 | 字段 |
| --- | --- |
| 标识 | 系统编码（只读）、客户名称、英文名称、外部码、SKU 前缀（只读，创建后不可修改） |
| 属性 | 客户类型、结算主体、状态（只读） |
| 地址 | 国家、州省、城市、区县、邮编、详细地址 |
| 其他 | 备注 |

### 页签二 · 联系人

表格列：姓名、职务、联系电话、邮箱、主要联系人、操作

顶部：新增联系人。主要联系人只能有一个，勾选新的会取消旧的。

### 页签三 · 税号

表格列：国家、州省、税号类型、税号、是否默认、操作

顶部：新增税号。支持多国多州，美国为 EIN 与州销售税号两类。

### 页签四 · 账号

主账号卡片：登录名（只读）、状态、最后登录时间、操作（重置密码、停用）

主账号未开通时，卡片处显示「开通主账号」按钮。

### 操作日志抽屉

右侧滑出，只读列表：时间、操作人、操作类型、变更前后值。取最近 100 条，超出给「查看全部」。

## 十、商品列表（仓网端）

**筛选栏**：SKUID、货主商品编码、商品名称、货主、品类、审核状态、启停状态

**表格列**：SKUID、商品名称、货主、品类、审核状态、启停状态、条码数、更新时间、操作

**操作**：查看、审核（仅待审核可用）、启停

**顶部**：无新建按钮。商品只能由货主创建，3PL 不代建。

## 十一、商品审核

三栏布局。

```
┌ 队列 ────┬ 商品内容 ──────────┬ 差异 ────┐
│ 待审核    │ 六段折叠（只读）    │ （仅重审）│
│ 12 条     │                    │ 变更字段  │
└──────────┴────────────────────┴──────────┘
              [ 通过 ]  [ 驳回 ]
```

**左栏 · 队列**

- 只列审核状态为待审核的商品
- 按提交时间升序，先进先出
- 顶部可按货主筛选
- 显示提交批次，支持整批选中

**中栏 · 内容**

与建档页同构的六段只读展示。

**右栏 · 差异**

仅在**重审版本**时出现。左右两栏对比生效版与待审版，变更字段高亮，新增标绿，删除标红。

**底部**：通过（待审版本覆盖生效版）、驳回（必须填写理由，回传货主端）

**顶部**：批量通过（按批次，逐条记审计）

---

## 十二、品类管理

左右分栏。

**左侧**：两级品类树。第三级不提供新增入口。

**右侧**：选中品类的详情

| 区块 | 内容 |
| --- | --- |
| 品类信息 | 名称、上级品类（一级为空）、排序、状态 |
| 必填项模板 | 字段清单勾选，勾中的字段在该品类商品提交审核时必填 |

**模板可勾字段**：含电池、电池类型、保质期天数、效期管理、批次管理、序列号管理、原产国、HS 编码。

**约束**：模板改动对所有货主立即生效。

## 十三、货主端商品列表

**筛选栏**：SKUID、货主商品编码、商品名称、品类、审核状态、启停状态

**表格列**：SKUID、货主商品编码、商品名称、品类、审核状态、启停状态、主条码、更新时间、操作

**操作**：查看、编辑、提交审核、启用/停用、打印标签

**顶部**：新建商品、批量导入

**约束**

- 待审核状态下编辑按钮置灰，提示「审核中不可修改」
- 已通过商品修改关键字段时，顶部提示「该修改需重新审核，审核期间线上仍使用上一版数据」

## 十四、货主端商品建档

单页六个折叠区，**不是分步向导**。

| 段 | 字段 |
| --- | --- |
| 基础信息 | 货主商品编码、商品名称、品类、品牌、计量单位 |
| 规格 | 单品长、宽、高、重量、体积 |
| 包装层级 | 单品 / 内箱 / 外箱，动态增行，每行填单位、条码、换算数量 |
| 条码 | 多行，可标一个主条码 |
| 合规 | 温区、含电池、电池类型、效期管理、保质期、批次管理、序列号管理 |
| 图片与备注 | 商品图片 1-5 张、备注 |

**品类模板联动**：选择品类后，模板要求的字段追加到「合规」段并自动标为必填，字段旁标注「该品类要求」。

**底部**：保存草稿、提交审核

**顶部提示条**

```
草稿状态：允许保存。还有 7 项未填，提交审核前需补齐。
```

必填标记始终显示，草稿阶段只提示不拦截。

## 十五、货主端商品批量导入

```
① 下载模板    [下载导入模板]
② 上传文件    [选择文件] 支持 .xlsx，单次最多 2 万行
③ 处理结果    进度条 + 成功/失败统计 + [下载错误报告]
```

**结果区**

```
本次导入 3,000 行：成功 2,987 行，失败 13 行
失败原因
  货主商品编码已存在   11 行
  条码已被本货主占用    2 行
```

**约束**

- 只新增不更新，已存在编码直接进错误报告
- 同一货主同时只能有一个导入任务，进行中再点提示等待
- 可离开页面，任务在后台继续

## 十六、货主端标签打印

从商品列表勾选或详情页进入。

**左侧 · 预览**

40 × 20 mm 标签实际尺寸：

```
┌──────────────────────┐
│ ██▀▀█▀▀██▀█▀▀███▀▀█ │
│ AMZ1000123           │
│ 宝洁（中国）          │
└──────────────────────┘
```

**右侧 · 参数**

| 项 | 说明 |
| --- | --- |
| 商品 | 已选商品名称与 SKUID |
| 张数 | 1-500，超出提示拆分 |
| 水印 | 草稿或待审核状态自动带「待审核」水印，不可关闭 |

**底部**：生成 PDF

**下方 · 打印记录**

表格列：打印时间、操作人、渠道、张数、模板版本。只展示当前商品。
