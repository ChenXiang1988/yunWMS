# 仓库网络任务（后续变更）

## 5. 仓库网络与空间模型

- [ ] 5.1 实现仓库档案与派生布局级别，验证布局级别随树结构自动变化、加盖楼层后原有库位编码不变
- [ ] 5.2 实现仓库服务能力独立表与能力字典，验证通过字典新增能力项无需改表结构
- [ ] 5.3 实现空间节点增删查与物化路径维护，验证子树查询能按楼栋或楼层一次取全、存在子节点时删除被拒
- [ ] 5.4 实现库区用途与功能区约束，验证仅存储区与拣货区可设专属货主、月台与拣选站不可建库位、全部实体库位参与盘点
- [ ] 5.4.1 实现库区作业模式与拣选站关联，验证同仓人工与自动化拣货区可共存、自动化区未指定拣选站被拒、人工任务候选排除自动化区库位
- [ ] 5.5 实现五段库位编码生成与层级完整性校验，验证多栋楼仓生成 `B1F3A-01-02-03-04`、平面仓生成 `A-01-01-01-01`、仓内重码与跳层建库位被拒
- [ ] 5.6 实现货架模板与批量生成，验证按模板一次生成整片库位（自动建巷道与货架，层号落在库位字段）、生成前预览数量准确、已存在货架号跳过且不覆盖、模板改层数不影响存量库位
- [ ] 5.7 实现库位容量四维配置与占用字段，验证未配置项不限制、配置为 0 表示不可存放、模板承载上限已快照到库位
- [ ] 5.8 实现库区货主归属与四维混放配置，验证专属库区拒绝他货主上架、库位收紧生效、库位放宽被拒、单 SKU 库位跳过条码比对
- [ ] 5.9 实现运输资源档案，验证按起点与终点双向可查
- [ ] 5.10 实现库位批量导入（异步、流式、分批、错误报告），验证 2 万行导入完成、错误行定位到行号、超限被拒、上级节点缺失时该行被拒
- [ ] 5.11 实现空间节点状态与删除，验证停用父节点不改子节点状态、子树全空且停用时一次级联删除、有库存时整批拒绝并列出、停用允许部分成功、无恢复入口、超 50 个节点要求输入名称确认
- [ ] 5.12 实现建仓向导，验证七个阶段状态按仓库独立计算、每行可直达对应页面、不强制阶段顺序
- [ ] 5.13 实现空间树逐层懒加载，验证首次只返回顶层、展开货架只返回该货架库位、1.5 万库位仓的响应量随深度而非总量增长
- [ ] 5.14 实现层号字段化，验证节点类型只有七种不含「层」、编码层段取自库位层号、同一货架下层数可不齐
