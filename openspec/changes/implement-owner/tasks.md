本变更不改行为，只做实现。任务编号按实现顺序排列，前两节是后两节的前置。

- [ ] 1.3 实现首次登录强制改密，验证未改密状态下除改密接口外均返回 401
- [ ] 1.4 实现会话失效与管理端踢人下线，验证旧令牌在失效后立即返回 401
