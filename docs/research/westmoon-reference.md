## 1. 站点性质

数字化跨境 B2B 平台，同时有买家、卖家、管理员三种角色。仓储是其中一块。

与 yunWMS 的立场差异：**它是甲方视角**（品牌管理自有的主仓 + 外部云仓 + 账务虚拟仓），我们是**乙方视角**（3PL 服务多货主）。判断字段是否适用时，先看这条。

## 3. 仓库管理

主从布局：左侧仓库列表（编码 + 名称 + 数量/虚拟仓标记），右侧详情 + 表格。

**顶部指标卡**：今日审单数、待出库单数、待生成批次单数、待拣货、拣货中、今日出库、今日发货。

**表格列**：序号、仓库编码、仓库名称、状态、仓库属性、建筑类型、仓库类型、仓库用途、国家、七个运营指标、更新人、更新时间、操作。

**枚举**：

| 字段 | 取值 |
| --- | --- |
| 状态 | 启用 / 草稿 / 禁用 |
| 仓库属性 | 主仓 / 云仓 / 虚拟仓 |
| 建筑类型 | 单层仓库 / 多层仓库 |
| 仓库类型 | 成品仓 / 原料、包材 |
| 仓库用途 | 分仓 |

**操作**：新增仓库、申请云仓；行内查看 / 编辑 / 配置空间 / 启用 / 禁用。状态页签带计数（全部 6、草稿 2、启用 2、禁用 2）。

## 4. 库位设置（配置驱动）

左侧仓库结构树，右侧三个页签：**楼层 / 库区 / 库位**，每个页签都是标准列表 + 筛选 + 详情 + 编辑。

### 楼层

字段：所属仓库、楼层编码（按仓库自动编号，前缀 `F`，两位）、楼层名称、状态、所属楼层、更新人。

### 库区

字段：所属仓库、所属楼层、库区编码、库区名称、**库区类型**、状态、**允许存放物料**、**禁止存放物料**、**品质类型**、**存储环境**、更新人、更新时间。

| 字段 | 取值 |
| --- | --- |
| 库区类型 | 拣选区 / 存储区 / 残次品区 / 暂存区 |
| 品质类型 | 良品 / 不良品 |
| 存储环境 | 常温 / 恒温 / 危险品 |
| 物料大类 | 成品 / 半成品 / 原材料 / 包材 / 配件 / 耗材 |

详情分两组：库区信息、存放规则。

### 库位

字段：所属仓库、库位编码、状态、所属楼层、所属库区、库区类型、**库位类型**、巷道、货架/列、层、位/格、库位尺寸、限重、**热度**、更新人、更新时间。

| 字段 | 取值 |
| --- | --- |
| 状态 | 可用 / 锁定 / 使用中 / 冻结 / 停用 |
| 库位类型 | 货架 / 地堆 |
| 库区类型（库位侧） | 拣选区 / 存储区 / 质检区 / 退货区 / 报废区 / 暂存区 / 次品区 / 待发区 / 其它 |
| 热度 | 热销 / 常销 / 滞销 / 不动销 |

规格分两组：巷道、货架/列、层、位/格、长宽高、限重，另有货架自身的长宽高与限重。

## 5. 容器管理

字段：容器编码、状态、所属仓库、容器类型、长、宽、高、载重。

| 字段 | 取值 |
| --- | --- |
| 状态 | 启用 / 禁用 / 占用 |
| 类型 | 周转箱 / 托盘 / 笼车 / 料箱 / 其他 |

「占用」表示容器正被库存使用，不可编辑。

## 6. 服务商品（三层）

```text
服务商品管理（定义） → 店铺服务商品（上架到店铺） → 平台服务商品（上架到平台）
```

服务商品字段：编码、名称、状态、分类、子类、仓库编码、仓库名称、时效（天）。

| 字段 | 取值 |
| --- | --- |
| 分类 | 仓储产品 / 物流产品 |
| 子类 | 不限 / 入库 / 出库 / 头程 / 尾程 |
| 状态 | 草稿 / 待审核 / 已核准或正常 / 禁用 |
| 上架状态 | 已核准待上架 / 上架 / 下架 |

店铺与平台层额外带有效期（起止日期）。

## 7. 仓库设计器（3D）

独立 iframe 应用。核心能力：

| 维度 | 内容 |
| --- | --- |
| 仓库外廓 | 多边形，可拖顶点改形、双击边加点、Alt+点删点；默认矩形 216×152 m |
| 楼层 | 有标高（+0 m / +24 m），可加层 |
| 柱子 | 逐根录入，方柱/矩形柱/圆柱 + 边长；**占库位、压缩通道净宽、参与容量与通行校验** |
| 通道 | 自动推导且幂等，保留人工设置的方向 / 限速 / 认领状态 |
| 区域 | 货架 / 穿梭 / ASRS / 功能 四类标签；月台、收货暂存、打包复核、充电区、空托盘区、办公更衣等 |
| 库位 | 空 / 占用 / 已满 / 锁定 / 禁用 五态着色 |
| 视图 | 展示与设计双模式、全景与单区、楼层切换、标签 / 热力 / 叠层 / 剖切、六类图层开关 |
| 编码 | 规则 `{floor}-{zone}-{row}-{bay}-{level}`，楼层位可开关，**深度位在 `depthSlots > 1` 时追加第 6 段** |

货架几何字段：位置 X/Y、朝向角、长宽高、深度、层数、离地高度、每格容量。地堆按 `groundStacks` 单独建模。

热力图实现：每个库位按热度等级上色，底部渐变图例（低 → 高）。热度来自库位的 `heatLevel` 属性。

## 9. 采纳建议

### 进首期模型（字段级）

1. 仓库加回「建筑类型」字段，人工录入，与空间树无关
2. 库区加「品质类型」（良品 / 不良品）
3. 库区加「允许存放物料 / 禁止存放物料」（按物料大类，可选）
4. 库位加「库位类型」（货架 / 地堆）
5. 库位加「热度」（热销 / 常销 / 滞销 / 不动销），首期人工标注，二期由动销计算
6. 库位编码支持第 6 段深度位，仅在库区设置深度大于 1 时出现

### 进首期界面（非模型）

7. 仓库列表状态页签带计数
8. 行内提供「配置空间」独立入口
9. 库位设置按「楼层 / 库区 / 库位」三个页签分开维护，而不是只有一棵树

### 二期

10. 容器管理独立模块（周转箱 / 托盘 / 笼车 / 料箱）
11. 服务商品三层上架模型，用于报价目录
12. 仓库列表的运营指标列

### 明确不做

13. 3D 渲染（剖切、叠层、屋面、等轴测）
14. 仓库外廓多边形编辑、柱子逐根录入与碰撞校验
15. 虚拟仓与云仓概念
