# CAD 解析可行性验证

- 验证时间：2026-10-23
- 时效：本文为 2026-10-23 的快照，记录当时状态；后续变化以仓库现状为准，本文不回改。
- 样本：`晧物仓改造1022.dwg`，58 MB，AutoCAD 2018 格式（AC1032）
- 结论：**可行，但需要处理多套平面与块嵌套**

## 1. 工具链

| 环节 | 工具 | 结果 |
| --- | --- | --- |
| DWG → DXF（LibreDWG 转） | LibreDWG 0.14 | 转出 213 MB，但 proxy 二进制损坏，ezdxf 读不进去 |
| **AutoCAD 原生 DXF** | ezdxf 1.4.5 | **成功**，249 MB 文件 14.2 秒加载，无报错 |
| DWG → JSON | LibreDWG `dwgread -O JSON` | 成功，1.0 GB JSON，860,234 个对象 |

结论：**要 AutoCAD 导出的原生 DXF，不要 LibreDWG 转的 DXF**。前者结构完整可直接解析，后者 proxy 数据损坏。若只有 DWG，用 `dwgread -O JSON` 兜底。

**关键教训**：统计图纸内容时必须同时遍历模型空间和全部块定义。`1007晧物仓.dxf` 的模型空间只有 47,851 个实体、货架层仅 32 个矩形，但块定义里藏着 559,820 个实体、15,656 个料箱位——只看模型空间会得出「这张图没有货架」的错误结论。

解析 JSON 时需注意两个坑：字符串里含有非 UTF-8 字节（用 `errors='replace'`）、存在裸控制字符（`json.load(..., strict=False)`）。

许可证提示：LibreDWG 是 GPL-3.0。做离线分析工具无碍，但不能静态链接进商业闭源产品。

## 3. 关键发现：料箱位是逐个画出来的

`Robots-货架` 图层里有 **16,088 个闭合多段线**，尺寸高度一致：

| 尺寸（图纸单位） | 数量 |
| --- | --- |
| 400 × 600 | 15,723 |
| 370 × 560 | 364 |
| 600 × 1400 | 1 |

400 × 600 mm 正是标准料箱的占位尺寸。**也就是说，这张图把每一个库位格都画出来了**，不是只画货架轮廓。

这意味着自动提取的精度远超「估算」——可以直接得到每个库位的真实坐标。

## 4. 组织结构

```
模型空间（77,551 个实体）
  └─ 16,421 个 INSERT
       └─ 每个引用一个块
            └─ 块内含 8 个 400×600 的料箱位矩形
```

- 含料箱位的块共 2,232 个引用，全部解析成功，提取出 15,794 个料箱位
- 每块 8 位，与「4 层 × 2 位」的标准货架结构吻合

## 5. 障碍：一个文件里有三套平面

模型空间的块分布聚在三个互不相邻的区域：

| 区域 | X 范围 | 说明 |
| --- | --- | --- |
| 区域一 | 约 100–400 m | 一套完整平面 |
| 区域二 | 约 2,300–3,000 m | 另一套完整平面 |
| 区域三 | 约 4,500–5,000 m | 第三套完整平面 |

非空网格 316 个，说明内容是「几张平面图并排摆在模型空间里」，而不是单张图。

推测是「改造前 / 改造后 / 分层平面」之类的对比图。解析时必须让用户指定用哪一套，或按包围盒最大者自动选。

## 6. 落地要做的事

| 步骤 | 说明 | 难度 |
| --- | --- | --- |
| 1. DWG → JSON | 调 LibreDWG，或要求客户导出 DXF | 低 |
| 2. 按图层提取 | 货架位、柱子、墙、AGV 路线 | 低 |
| 3. **选择平面** | 按空间聚类分组，让用户挑一套 | 中 |
| 4. 块嵌套展开 | 递归应用平移/旋转/缩放 | 中 |
| 5. 坐标归一 | 平移到原点、单位换算成米 | 低 |
| 6. 转成库位模型 | 按行列聚类生成巷道/货架/层/位，或直接采用图纸的行列 | 中高 |

第 6 步是关键：图纸给的是「一个个格子的坐标」，要变成「区-巷道-货架-层-位」的层级结构，需要按坐标聚类反推行列。这一步做得好，能自动生成 1.5 万个库位；做得糙，会得到一堆散点。

## 7. 产品结论

1. **DWG 不直接支持**，让客户导出 DXF；LibreDWG 只作为内部工具，不进入产品（GPL）。
2. **DXF 支持值得做**，但只在「图层规范」时有效。这张图的规范度是理想情况，不代表客户平均水。
3. **解析结果必须人工确认**：选平面、看行列、修正异常，不能全自动。
4. **最有价值的不是省掉描图，而是拿到真实坐标**——这是库位级热力图和容量校验的数据基础。
