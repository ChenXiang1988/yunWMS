# 仓库平面图交付规范 v0.2

- 适用：客户成功团队为建仓交付的仓库平面图
- 目的：只交付**物理空间事实**，货架与库位由系统展开或生成
- 状态：草案，待试用一轮后修订

## 1. 分工原则

**图纸画看得见摸得着的东西，系统算能推导出来的东西。**

| 谁做 | 做什么 |
| --- | --- |
| 客户成功团队 | 画外轮廓、柱子、设施、月台、货架带 |
| 系统 | 按货架规格展开成货架与库位；无货架带时自动排布 |

团队**不画**单个料箱格、不画机器人、不画输送设备、不画装修。

## 2. 两档交付

| 档位 | 团队画什么 | 适用 | 绘制量 |
| --- | --- | --- | --- |
| **L4 空间** | 只画外轮廓、柱子、设施、月台 | 新仓、改造仓，货架方案未定 | 几百个实体，2-3 小时 |
| **L3 货架带** | L4 全部 + 货架带矩形 | 现状仓，货架已装好；或方案已确定 | 加 100 个矩形，1 小时 |

L3 每条带代表**一排背靠背货架**（两侧都能取货），不是单个货架。

## 3. 文件

| 项 | 要求 |
| --- | --- |
| 绘图软件 | AutoCAD，模型空间 1:1 |
| 单位 | 毫米，`INSUNITS = 4` |
| 存档 | `.dwg` |
| 交付 | **另存为 `.dxf`**（下拉选 AutoCAD 2018 DXF），不要用插件导出 |
| 命名 | `{仓库编码}_{仓库简称}_{YYYYMMDD}.dxf` |
| 平面 | 一个文件只放一套平面 |

导出前执行 `PURGE`，清理无用图层与匿名块。图框放布局空间。

## 4. 图层

| 图层 | 内容 | 实体类型 |
| --- | --- | --- |
| `OUTLINE` | 仓库外墙闭合轮廓 | 闭合 `LWPOLYLINE` |
| `COLUMN` | 柱子 | 闭合矩形或 `CIRCLE`，按实际尺寸 |
| `FACILITY` | 楼梯、电梯、厕所、办公区、消防通道、设备间 | 闭合多段线 + `TEXT` 名称 |
| `DOCK` | 月台、大门、卷帘门 | 闭合多段线 + `TEXT` 名称 |
| `AISLE` | 主干通道 | 闭合矩形或 `LINE` 中心线 |
| `ZONE` | 库区边界（有物理隔断时才画） | 闭合 `LWPOLYLINE` + `TEXT` 区编码 |
| `BAND` | 货架带（仅 L3） | `INSERT` |
| `TEXT` | 其他标注 | `TEXT` / `MTEXT` |

标准内容不得画在 `0` 层。

## 5. 货架带（L3）

### 5.1 块名即规格

```
BAND-{层数}L{每层位数}P
```

示例：`BAND-4L2P` = 4 层 × 每层 2 位。

- 块内容：**一个矩形**，尺寸等于带的平面占位（长 × 深）
- 带的**长边方向**为货架排列方向，即巷道走向
- 一个块可以被复制多次，位置不同、块名相同

### 5.2 系统如何展开

```
带的长度 ÷ 货架长度（取整）= 该带的货架数
货架数 × 层数 × 每层位数 = 该带库位数
```

示例：带长 54 m、货架长 2.7 m → 20 个货架 → 20 × 4 × 2 = 160 个库位。

### 5.3 柱子避让由团队处理

遇到柱子时，**把一条带拆成两条短带**绕开，不要让带穿过柱子。

系统不做几何避让计算，只做除法。这样规则简单、结果可预测。

## 6. 禁止事项

| 禁止 | 原因 |
| --- | --- |
| 画单个料箱格 | 系统按规格展开，画了反而冲突 |
| 画机器人、输送线、分拣设备 | 自动化区用库区属性表达，不需要设备图形 |
| 画装修家具、洁具 | 与仓储无关，文件膨胀 |
| 一个文件多套平面 | 无法判断用哪套 |
| 使用天正等插件的自定义对象 | 导出后变代理对象，几何读不出 |
| 块缩放表达规格差异 | 尺寸读不准 |
| 非 1:1 比例 | 全部失真 |

## 7. 交付前自检

- [ ] 单位 mm，模型空间 1:1
- [ ] 只有一个平面
- [ ] 外轮廓闭合，只有一个
- [ ] 柱子逐根画出，尺寸真实
- [ ] 楼梯、电梯、厕所、办公区都有标注
- [ ] 月台、门有标注
- [ ] L3：所有货架带块名符合 `BAND-{层}L{位}P`
- [ ] L3：没有带穿过柱子（遇到柱子已拆段）
- [ ] 无代理对象、无隐藏图层残留
- [ ] 已另存为 DXF

## 8. 系统侧需要配的参数

图纸不表达这些，在系统里填：

| 参数 | 说明 |
| --- | --- |
| 货架规格 | 长、深、高、层高 |
| 通道宽度 | 主通道、支通道 |
| 货架模板 | 层数、每层位数、单库位承重 |
| 库区属性 | 用途、温区、混放策略、专属货主、作业模式 |

## 9. L4 自动排布（系统能力）

没有货架带时，系统按以下输入生成排布方案：

```text
外轮廓 − 柱子 − 设施 − 月台 − 主干通道 = 可用区域
按「带深 = 2 × 货架深 + 通道宽」切分可用区域
每条带内按「货架长」切分
```

输出方案后允许人工调整：拖动带、改层数、拆段。**不做全自动定稿。**

首期只支持矩形区域自动排布，异形区域要求人工画带。

## 10. 待验证

1. 货架带的"长边方向"约定，是否与现场巷道走向一致
2. 双深位货架如何表达（带深不同）
3. 多楼层：一个文件多个模型空间，还是每层一个文件
4. L4 排布结果与人工方案的差异有多大
