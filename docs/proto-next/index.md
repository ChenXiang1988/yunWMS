### 设计简报（DESIGN.md）

`specs/` 是给人看的规范，`DESIGN.md` 是给 AI 编码代理读的索引层。分工：`AGENTS.md` 说怎么干活，`DESIGN.md` 说该长什么样。

| 文件 | 适用范围 | 说明 |
| --- | --- | --- |
| [DESIGN.md](../DESIGN.md) | 全仓 | 跨端硬约束、真值分层（规范层 / 实现层 / 索引层）、语义色裁决、零外链与端间隔离 |
| [proto-next/pc/DESIGN.md](../proto-next/pc/DESIGN.md) | PC 后台 | 紫系令牌、ListPage 骨架、组件与页面纪律 |
| [proto-next/app/DESIGN.md](../proto-next/app/DESIGN.md) | APP 手持 | 绿系令牌、375 视口、44px 触控、机身舞台规则、28 项令牌缺口清单 |

**索引层不得新增取值**：三份文件里出现的每个 hex 都必须在实现层（`baseline-tokens.css.mjs` / `tokens.css` / `pda-ui-tokens.json`）原样找到，由 `node tools/check-design.mjs` 强制。
