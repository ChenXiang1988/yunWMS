本页只收已定条目。未定项不收录。

## 一、收录条件

一条边界进本页，须同时满足三条。

1. 用户裁决内容。
2. 用户裁决类型，背景或约束。
3. 条目带来源号与裁决日。

缺一条不进本页。

## 二、条目字段

| 字段 | 要求 |
| --- | --- |
| 编号 | `BND-01` 起。发布后不改 |
| 类型 | 背景或约束 |
| 边界对象 | 一句话，可改写为问句 |
| 界内 | 本产品做什么 |
| 界外 | 本产品不做什么 |
| 交接点 | 两边的现场动作与交接物 |
| 执行点 | 约束类必填。背景类留空 |
| 依据 | 来源号与裁决日 |

## 三、已定条目

### BND-01 主体的仓网以总仓为根

| 字段 | 内容 |
| --- | --- |
| 编号 | BND-01 |
| 类型 | 约束 |
| 边界对象 | 主体的仓网是否以总仓为根 |
| 界内 | 每个主体有一个总仓节点，作为仓网根。只有一座实体仓的主体同样有总仓。 |
| 界外 | 总仓不是实体仓。总仓不承接实体作业。 |
| 交接点 | 主体开通时建总仓。创建实体仓时归入该主体的总仓。 |
| 执行点 | 待定。主体开通页与仓库创建页未落。 |
| 依据 | F-12、F-13、F-46、F-49。裁决日 2026-10-29。 |

### BND-02 库存数量以本模块为准

| 字段 | 内容 |
| --- | --- |
| 编号 | BND-02 |
| 类型 | 约束 |
| 边界对象 | 库存数量以谁为准 |
| 界内 | 本模块记数量账。账按主体、仓、库位、SKU、批次、货主、库存状态记录。所有数量变动经统一过账。 |
| 界外 | 金额账与财务凭证不在本模块。上游不得直接改数量。 |
| 交接点 | 上游下发单据。本模块回传过账凭证。 |
| 执行点 | 待定。收货过账、发货过账、盘点调整三个入口未落。 |
| 依据 | F-03、F-04、F-26、F-50。裁决日 2026-10-29。 |

### BND-03 商品档案只引用，不复制

| 字段 | 内容 |
| --- | --- |
| 编号 | BND-03 |
| 类型 | 约束 |
| 边界对象 | 商品档案数据是否在本模块存副本 |
| 界内 | 本模块只存 SKU 编码引用。单据行存快照五项：名称、规格、条码、单位、箱规。快照随单据冻结。 |
| 界外 | 不复制商品主数据。不维护商品档案的增删改。 |
| 交接点 | 建单时从商品模块取数，写入单据行快照。 |
| 执行点 | 待定。建单页取数校验未落。 |
| 依据 | F-08。裁决日 2026-10-29。 |
