## agent 遵守约定

- 产出 PC / APP 原型或汇报 HTML 前，先读 01 / 02 / 03 中对应的一份。
- 改动 `proto-next/pc/` 前，除 01 外还须遵守 05（页面骨架唯一、不发明菜单与列名、分页须真能切页）。
- **任何会话都须遵守 04（环境论断核查）**：单源不采信、否定结论须双证据并限定作用域、论断须可回溯到本次真跑过的命令。
- 配色、字号、间距、圆角一律取自规范令牌，不得自创新值。
- 全工作区「零外链」规则对所有交付物生效（不引 CDN、不引网络字体、不引图片外链）。

## 机器检查（待实现）

- 检查脚本只依赖 Node 标准库，不安装依赖，符合工作区构建约束。
- 脚本读取规范令牌作为期望值，assert 交付物不偏离；偏离即报错，由 agent 或人修订后重跑。
