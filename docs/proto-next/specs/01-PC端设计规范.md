# PC 端（后台）设计规范

> 适用范围：所有 PC 后台原型（`proto-next/pc/`）与后台汇报 / 演示 HTML。
> 资料来源：`../web 端原型模板_20261013.html`（视觉基线，唯一权威来源）。

## 1. 设计令牌

### 颜色

主色 primary：
- 50 `#f3efff` / 100 `#ece4ff` / 200 `#d9caff` / 400 `#8a5cff` / 500 `#6424fe` / 600 `#6424fe` / 700 `#4f1bcc`

灰阶 gray：
- 0 `#ffffff` / 50 `#f5f5f5` / 100 `#f1f2f4` / 200 `#e5e5e5` / 300 `#d1d5db` / 400 `#8a8f98` / 500 `#687386` / 600 `#545b68` / 700 `#414753` / 800 `#30343b` / 900 `#171717`

语义色：
- error `#e5484d` / success `#1f9d65` / warning `#d97706`
- warning-soft `#fff7e6` / success-soft `#eaf8f1` / danger-soft `#fff0f0` / disabled-soft `#f1f2f4`
- surface-sunken `#fafafa` / row-hover `#fcfbff` / row-selected `#f7f3ff`

### 布局
- 顶栏高度 `--topbar-height: 54px`
- 侧边栏宽度 `--sidebar-width: 188px`（收起 `--sidebar-collapsed-width: 64px`）

### 圆角
- `--radius-sm 6px` / `--radius-md 6px` / `--radius-lg 8px` / `--radius-pill 999px`

### 阴影
- `--shadow-sm 0 1px 2px 0 rgb(0 0 0 / .05)`
- `--shadow-md` / `--shadow-soft` / `--shadow-lift` / `--shadow-panel`（完整取值见基线文件）

## 2. 结构约定
- 顶栏 + 左侧导航 + 内容区三栏；内容区用表格 / 卡片承载业务数据。
- 每个区域主操作不超过 1 个主按钮；危险操作用 error 色并二次确认。
- 字体使用系统字体栈，不引入网络字体（遵守零外链规则）。

## 3. 机器检查项（部分已实现）
- [ ] 交付 HTML 的 `:root` 颜色变量须为上方令牌子集，不得出现其它硬编码色值
- [ ] 不得出现 `<link href="http...">`、`<script src="http...">`、CDN 域名、`@import url(http`
- [ ] 圆角取值仅限 `{6, 6, 8, 999}px`
- [ ] topbar / sidebar 尺寸与令牌一致
- [x] **已实现**：不同页面模块不得定义同名 CSS 类。同名会互相覆盖，
      典型故障是 `.hw-drawer` 一个当全屏遮罩（`inset:0`）一个当右侧抽屉（`right:0`），
      结果抽屉被拉满全屏、跑到左侧。校验器 `shared/verify-class-names.mjs`，构建期自动拦截（见 A.11.9.147）
- [ ] 抽屉与弹层须挂 `body`，不得内联在 `.page` 内；`.page{display:none}` 会连带隐藏弹层，
      导致切页后按钮点击无反应（见 A.11.9.122）
