执行单元是什么

先讲使用方

执行单元是任务归属，不是硬件包。一个任务同一时刻只归一个单元。

人 + 输入

人负责；终端是工具，移动用 PDA、工位用 PC + 扫码枪；换机不换单元。

AGV

设备负责；责任绑角色；资产与单元两条记录。

工位

工位负责；硬件聚合；人可在工位内轮换。

六类接入样例

AGV

厂商服务

接口：车队接口或 VDA 5050。

地址：https://fleet.example.com/api/v1

连接：Wi-Fi / 5G，走车队服务。

动作：下发搬运、取消、回充；收到达与位置。

要点：地图、任务号映射、心跳、电量。

流水线

WCS / PLC

接口：WCS 或 PLC 网关，OPC UA / 点位表。

地址：https://wcs.example.com/api/v1

连接：工业网，固定线体。

动作：下发道口、改道；收通过事件。

要点：点位表、堵塞/急停、握手时序。

打印机

本地 PC

接口：PC/打印代理（C-Lodop 或 hiprint）。

地址：http://127.0.0.1:8000/c-lodop

连接：USB 到 PC，系统不直连。

动作：提交模板 + 数据，取标签号。

要点：模板版本、打印机名、队列。

称重机

本地 PC

接口：PC/称重代理，驱动或 SDK。

地址：COM3 / 9600

连接：串口 / USB 到 PC。

动作：读重量，判稳定，取校准状态。

要点：波特率、量程、校准、去皮。

摄像头

外部服务

接口：外部视频服务商接口。

地址：https://video.example.com/api/v1

连接：服务商连摄像头，系统只调服务。

动作：抓拍、取片段，拿媒体号。

要点：覆盖区域、鉴权、保留期。

PDA

我们的 App

接口：我们的 App，Wi-Fi 连系统。

地址：wss://wms.example.com/pda

连接：不依赖 PC，移动使用。

动作：扫描、输入、确认，上报心跳。

要点：App 版本、能力清单、离线队列。

AGV 接入

项内容
接口车队接口或 VDA 5050（MQTT/JSON）；3.0.0 已发布，现场按车队支持版本。
身份厂商 + 序列号；MQTT 主题按车队配置。
连接Wi-Fi/5G；MQTT 代理或车队端点；心跳与连接状态。
任务WMS 搬运单 → 搬运单（任务单号、更新号、节点/边/动作）；取消、暂停、充电走即时指令。
状态状态报文：订单进度、最后节点、位置、电量、行驶状态、错误；可视化供地图展示。
地图节点/边、区域限速、禁行区、电梯/门；交通管制由车队服务负责，VDA 5050 不管。
产出物到达节点、位置、时间、电量、订单完成状态。
异常离线、阻塞、低电、手动模式、车队服务不可用 → 改派另一台或转人工叉车。
与流水线不同移动设备，走车队服务，要地图/电量/交通；固定设施，走 WCS/PLC，要点位表/堵塞/急停/握手。

AGV 搬运链路

相同与不同　打印机和秤都挂 PC、都走本地口，但打印机是任务型（模板 + 标签号），秤是读数型（稳定 + 校准）；AGV 走车队接口或 VDA 5050，流水线走 WCS/PLC，两者接入方式不同；摄像头不接设备，接外部视频服务商。

07

适配器的四个动作

执行单元通过它调用硬件

自报能力

适配器把设备的能力说清楚：能做什么、要什么参数、回什么结果、是什么版本。建档和换型号时用。

探活

适配器问设备一句现在能不能用：在线、就绪、故障、心跳。派活前和定时巡检时用。

执行

执行单元把命令交给适配器，适配器下发给绑定的硬件：打印、称重、抓拍、搬运；设备干完，把结果和产出物带回来。

订阅

适配器订阅设备状态，一变就主动告诉你：完成、故障、离线。不用一直问。

先自报，再看能不能用；能用就下命令，变化靠订阅。

08

怎么用公共能力

四种取用面 + 一条完整链路

引用、继承、聚合、消费不是四个步骤，是每一步都会发生的四个取用面：先引用设备，再继承能力，聚合状态判断可用，最后消费产出物。下面用拣货 → 打印 → 称重 → 拍照走一遍。

引用打印机、秤、摄像头
继承扫描、打印、称重、取证
聚合人的状态 + PC/设备状态
消费标签、重量、照片

打印 / 称重链路

时序图只画打印与称重；拣货与拍照见下表。

步骤执行单元链路与依赖产出物缺失兜底
拣货人 + 输入 · 扫描PDA 经 Wi-Fi 连系统扫描流水手工录入
打印打印站 · 打印系统 → PC（C-Lodop/代理）→ USB 打印机标签号换机或手写
称重称重站 · 称重系统 → PC（代理）→ 串口/USB 秤重量 + 稳定换秤或复核
拍照质检站 · 取证系统 → 外部视频服务商 → 摄像头媒体号 + 时间人工拍照

打印机、秤不直连系统：系统到 PC/代理，PC 再到设备。摄像头走外部视频服务商的接口，不自建监控管理。产出物回写任务，成为证据。

共享与绑定

硬件不是单元私有
关系例子怎么理解
绑定打包台的扫码枪坏了，换 SC-06张伟还是同一个执行单元，任务不改派，只换扫码枪引用。
共享一台打印机服务 3 个拣货员打印机不属于任何一个人；三个人都引用它，打印任务排队，产出物带打印机编号。
自身AGV-01 既是资产，也是单元资产记录管序列号、固件、维护；单元记录管任务、负荷、班次；两条记录 1:1 关联。

共享设备不归单元所有，单元只是引用；绑定设备换机时只换引用，单元编号不变。
