## 二、两条口径订正（用户于本轮补正）

### 2.1 单元编号与硬件编号必须不同源

现行数据把单元编成了硬件的别名：101 条里 96 条 `EU-HP-001 ← PDA-01` 完全按硬件尾号派生，只有 5 条手机单元尾数错开（`EU-PH-101 ← PHONE-01`）。

**订正**：单元是作业主体的编号，硬件是工具，两者是不同对象，编号不得同源派生。以工号派生（`EU-EMP-*`）不是「为了换机不改号」的便利做法，而是模型要求——单元的主体是人，编号就该跟主体。

判定口径：拿到一个单元编号，应能反查**是谁**；拿到硬件编号，应能反查**哪台设备**。两者互不承担对方的语义。

### 2.2 一人一单元 = 同一时间只有一个入口能执行

原记录把 A4 写成「入口列支持多值（`PDA-05 / PC-01`）」，这是「同时多入口」，与一人一单元冲突。

**订正**：一个人只有一个单元；该单元在**任一时刻只指向一个入口**；换入口是换指针，不是加指针。同一时间段内不存在「此人用 PDA 也在用 PC」。

数据侧现况已符合，无需迁移：85 条在岗单元每条 `terminalId` 均为单值，无一条挂两个入口，也无一人多行。
