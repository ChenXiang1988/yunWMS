# 入库确认清单

用法：每条回一个字母。拿不准写「待定」。

## A 两段边界

A1 「入库」到哪一步结束？
A 收货核对并过账　B 上架入存储位　C 两者都算

A2 货什么时候可拣？
A 收货即可拣　B 上架才可拣

A3 上架单归哪一段？
A 入库　B 库内

A4 暂存位与落位谁管？
A 入库占、库内只看　B 库内统一管

A5 拒收与不良品归哪一段？
A 入库判定并转隔离　B 库内处理

## B 入库单结构

B1 一张入库单能否多次收货？
A 全部类型允许　B 按类型区分　C 全部只允许一次

B2 能否多次预报？
A 允许　B 不允许

B3 预报是否必填？
A 必填，无预报不能收　B 可选　C 不需要

B4 是否允许无预报到货？
A 允许，事后补挂　B 禁止

B5 是否允许一车多单（拼车）？
A 允许　B 禁止

B6 是否允许一包裹多单（拼包）？
A 允许　B 禁止

## C 规则

C1 手工建单是否需要审核？
A 必须　B 免审　C 按数量或金额设阈值

C2 超收容差？
A 不允许超收　B 固定比例　C 按货主配置

C3 收货单位层级（包裹-箱、箱、包裹）本期是否做？
A 本期　B 下期　C 不做

C4 单据状态机用哪套？
A 文档八态　B 原型五态

C5 送货信息（车牌、运单、到仓时间）挂在哪一层？
A 单据头　B 预报　C 车次

C6 包裹号唯一性范围？
A 单内　B 车次内　C 全局
