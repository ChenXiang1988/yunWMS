# 硬件与执行单元怎么分工

2026-10-29 起，硬件范围改为 PDA、PC 与四类外设，执行单元改为运行时资源。本文第 2 节至第 5 节为旧口径，只留历史。新口径以 `DOC-SPC-001` 与 `DOC-SPC-002` 为准。

## 一、一句话分工

硬件是供给方，回答「怎么连、能不能用、返回什么」。执行单元是使用方，回答「任务归谁、接什么、够不够」。

判据用一句话分：要问「这台设备怎么接」的，归硬件；要问「这个任务归谁」的，归执行单元。

## 二、两层各管什么

| 维度 | 硬件 | 执行单元 |
| --- | --- | --- |
| 回答 | 设备怎么连、什么状态、能下什么命令、返回什么证据 | 任务归谁、接什么任务、能力够不够、负荷多少 |
| 单位 | 设备类、设备实例 | 人工 + PDA、AGV、通用智能设备 |
| 范围 | 全局标准加仓库实例 | 仓库编制加班次区域 |
| 产出 | 状态、命令、产出物 | 任务归属、接收契约、负荷 |
| 变化 | 型号、固件、协议 | 排班、契约、任务 |
| 关系 | 供给 | 使用 |

硬件不承接任务。一个任务同一时刻只归一个执行单元。

## 三、七类硬件与可派性

| 设备类 | 能力 | 可派任务 | 产出物 | 兜底 |
| --- | --- | --- | --- | --- |
| 打印机 | 打印 | 否 | 标签号 | 手写标签 |
| PDA | 扫描 | 否 | 扫描流水 | 手工录入 |
| 摄像头 | 取证 | 否 | 媒体号 | 人工拍照 |
| 称重机 | 称重 | 否 | 重量加稳定标记 | 复核或称重 |
| 监控 | 只读 | 否 | 无 | 无 |
| AGV | 搬运 | 是 | 到达节点 | 转人工叉车 |
| 流水线 | 输送 | 是 | 道口通过 | 人工搬运 |

设备类只此七类，不扩。以下三种形态并入，不单列：叉车并入 AGV 类，作移动搬运形态；电子标签并入流水线类，作分拣辅助形态；扫码枪并入 PDA 类，作固定输入形态。PC 不作设备类，作接入代理写在实例的接入代理字段。

可派任务只两列：AGV 类与流水线类。打印机、秤、摄像头、PDA、监控都不单独派任务，它们被单元或工位引用。

监控与摄像头分工：摄像头在作业点取证，产出媒体号；监控看区域，只读，不派任务，不产生证据。两者都走外部视频服务商，不自建监控管理。

## 四、三种绑定关系

| 关系 | 判据 | 例子 | 数据表达 |
| --- | --- | --- | --- |
| 绑定 | 随身终端与单元一对一 | 张伟用 PDA-01，换机仍是同一单元 | 关系值 `bound` |
| 共享 | 多使用方引用同一台 | 一台打印机服务三个拣货员 | 关系值 `shared` |
| 自身 | 资产与单元一对一 | AGV-01 既是资产也是单元 | 关系值 `self` |

关系只存一处：硬件台账的绑定表。执行单元行与工位行都不另存硬件清单，避免两份字段漂移。

维护归属按使用方分：执行单元引用哪些硬件，在执行单元页维护；工位绑定哪些硬件，在库位管理维护；硬件页只读显示被谁引用，不提供编辑。

## 五、能力怎么判

两条轴要分开陈述。

- 工序能力：拣货、移库、上架、质检、盘点等，由人员技能与执行单元类型决定。
- 设备能力：扫描、打印、称重、取证、搬运、输送，由硬件自报。

分配时两条都查。缺工序能力剔除候选；缺设备能力按下面的三步判。

覆盖判定三步：

1. 汇总任务动作的设备能力，去重。
2. 取执行单元引用的硬件。
3. 每种能力：有在线同类实例即齐；无在线实例但设备类有兜底即走兜底；两者都无即缺。

兜底不是阻断。执行点有两处：分配候选卡列出兜底方式并降分，任务抽屉列出缺口与兜底。两处都说清「换机还是走兜底」，才算这条约束有执行点。

## 六、工位放在哪

工位是库位的一种类型，取值为 `binType=工位`，不是执行单元，也不是硬件。

本轮只动三处：

1. 库位表格加「绑定硬件」列，最多显示三个，超出折叠为 `+N`。
2. 空间配置抽屉的工位表单加「绑定硬件」多选，从本仓硬件台账取，保存写绑定表。
3. 设备地址的标签改为「设备地址（WCS）」，与绑定硬件分成两个概念：前者是对接控制系统的地址，后者是实物。

工位不承接任务。汇报稿里「工位负责」这条本轮未落，登记为缺口。

## 七、证据怎么回写

试跑走七段链路：任务、执行单元、能力、硬件、适配器、产出物、证据。

证据行五项：类型、值、来源硬件、适配器、时间。

| 能力 | 证据类型 | 值的形态 |
| --- | --- | --- |
| 扫描 | 扫描 | SKU 加数量 |
| 打印 | 标签 | 标签号 |
| 称重 | 重量 | 数值加稳定标记 |
| 取证 | 媒体 | 媒体号 |
| 搬运 | 到达 | 到达节点 |
| 输送 | 通过 | 道口号 |

试跑只写证据，不改任务状态。任务已有接单、执行、完成三态，试跑若改状态会与状态机冲突。

硬件不可用时，试跑不产生证据，只显示兜底方式。

## 八、未落与缺口

四条，均登记不实现：

1. 工位不承接任务。任务归属仍只有人工 + PDA、AGV、通用智能设备三类。
2. 输送线、电子标签不进执行单元池。它们只进硬件台账与设备下发。
3. 监控只读，不派任务，不产生证据。
4. 探活与命令为模拟。原型不接真实设备，命令结果由适配器展示。
